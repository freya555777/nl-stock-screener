> 目标：把本产品部署到公网，获得一个评审可访问的 URL（如 
>
> `https://nl-stock-screener.onrender.com`
>
> ）。
> 总耗时约 10–15 分钟。
>
> **需要你本人操作的步骤已用 ⚠️ 标出**
>
> （注册 / 登录类账号操作我无法代办）。

## 0. 前置准备（⚠️ 需你本人完成）



1. 注册 GitHub 账号：[https://github.com/signup](https://github.com/signup)（邮箱即可）

2. 注册 Render 账号：[https://render.com](https://render.com) 用 GitHub 账号登录即可（无需单独注册）

## 1. 把代码上传到 GitHub

本地代码已就绪：`C:\Users\HP\Doubao\chats\2026-10-12\new-chat\nl-stock-screener`（git 仓库已初始化并完成首次提交）。

### 方案 A：网页上传（零命令行，最快）



1. 登录 GitHub → 右上角 **+ → New repository**

2. 仓库名填 `nl-stock-screener`，选 **Public**（评审需要无权限访问），不要勾选任何初始化文件

3. 创建后进入仓库页 → 点 **uploading an existing file**（"上传文件"）

4. 把 `nl-stock-screener` 文件夹里的**全部内容**拖入上传区（**不要**把文件夹本身拖进去，要文件直接出现在仓库根目录；`.git` 文件夹不用传）

5. 底部 Commit changes 直接提交

### 方案 B：本地 git 推送（我已建好本地仓库）



1. 在 GitHub 创建仓库（同上，Public）

2. 创建 "个人访问令牌"：GitHub → Settings → Developer settings → Personal access tokens → Generate new token（勾选 `repo` 权限，有效期选 90 天）

3. 回到本地，在 `nl-stock-screener` 目录执行（⚠️ 替换为你的账号与令牌）：



```
git remote add origin https://github.com/<你的用户名>/nl-stock-screener.git
git branch -M main
git push -u origin main
# 弹窗提示输入用户名时填 GitHub 用户名，密码处粘贴令牌
```

## 2. 在 Render 部署



1. 登录 [render.com](https://render.com) → 点 **New + → Web Service**

2. 选择 **Connect** 你刚建的 `nl-stock-screener` 仓库

3. 保持默认（Render 会自动读取我已写好的 `render.yaml`：Python 3.12、`python app.py`、健康检查 `/api/health`）

* 若没自动识别，手动确认：Runtime = Python；Build Command = `pip install -r requirements.txt`；Start Command = `python app.py`

1. 点 **Create Web Service**

2. 等 3–5 分钟构建部署，页面顶部出现 `https://nl-stock-screener.onrender.com` 即成功

## 3. 验证（⚠️ 建议你本人做）



1. 电脑 / 手机浏览器（建议**手机流量 + 无痕窗口**，模拟评审网络）打开你的 URL

2. 页面应显示 "选股意图解释器"，点示例句 → 解析 → 筛选，确认能跑通

3. 点 "刷新实时行情"，确认行情字段能更新（腾讯行情接口对公网开放）

4. 把 URL 复制保存，这就是你提交答案时填的 "可访问 Web 产品 URL"

## 4. 常见问题



| 问题                     | 处理                                                                               |
| ---------------------- | -------------------------------------------------------------------------------- |
| Render 免费实例闲置 15 分钟会休眠 | 评审打开时首次加载约 10–30 秒，属正常；可在演示前先访问一次预热                                              |
